# 🟢 Supabase সেটআপ গাইড — উত্তরবঙ্গ হেরিটেজ ফেস্ট

পুরো সাইট (পরীক্ষার লক, প্রশ্ন, রেজিস্ট্রেশন, লিডারবোর্ড) এখন Supabase
(Postgres + Realtime) থেকে চলে — যেকোনো ডিভাইস, যেকোনো ব্রাউজারে।
Firebase সম্পূর্ণ সরানো হয়েছে।

| ফাইল | কাজ |
|---|---|
| `src/shared/supabase-config.js` | URL + anon key (ইতিমধ্যে বসানো আছে) |
| `src/shared/supabase-db.js` | Supabase-এর সব কথাবার্তা (এক জায়গায়) |
| `supabase/schema.sql` | টেবিল + RLS + RPC + Realtime — এক রানে সব |
| `src/shared/settings.js` | পরীক্ষার লক/তারিখ + বাংলা তারিখ হেল্পার |

## ধাপ ১ — SQL চালাও (২ মিনিট) ⭐ এটাই এখন বাকি

1. [supabase.com/dashboard](https://supabase.com/dashboard) → প্রজেক্ট
   (`zlqwmpatcamochqmivxi…`) খোলো
2. বাম মেনু → **SQL Editor** → **New query**
3. রিপোর **`supabase/schema.sql`** ফাইলের পুরো কনটেন্ট পেস্ট করো → **Run**
4. সবুজ `Success` দেখলেই টেবিল, পলিসি, RPC, Realtime — সব তৈরি ✅

*(ঐচ্ছিক) পুরনো পরীক্ষামূলক `participants` টেবিল থাকলে চাইলে মুছে দাও —
আমাদের এটার দরকার নেই।*

## ধাপ ২ — আয়োয়ক অ্যাকাউন্ট (১ মিনিট)

1. **Authentication → Users → Add user** → Email + শক্ত পাসওয়ার্ড → Create
2. এই অ্যাকাউন্ট দিয়েই `/admin`-এর **☁️ আয়োজক সাইন-ইন** বক্সে ঢুকবে —
   সুইচ ঘোরানো/প্রশ্ন সম্পাদনা/রেজিস্ট্রেশন তালিকা দেখা তারপরই সম্ভব
   (RLS শুধু signed-in আয়োয়ককে লেখার অনুমতি দেয়)।

অ্যাডমিন লগইন (`muhit123`) আগের মতোই আলাদা ও লোকাল — এটা প্রথম দরজা মাত্র।

## ধাপ ৩ — বিল্ট-ইন প্রশ্ন একবারে আপলোড (ঐচ্ছিক, ১ ক্লিক)

`/admin` → প্রশ্ন ম্যানেজমেন্ট → ক্যাটাগরি বেছে **"পুরনো প্রশ্ন লোড করো"** —
কোডে বানানো নমুনা প্রশ্নগুলো টেবিলে ঢুকে যাবে (টেবিলে আগে থাকলে কিছু
করবে না — ডুপ্লিকেটের ভয় নেই)। এরপর সেগুলো সম্পাদনা/মুছে নিজের প্রশ্ন বসাও।

## টেস্ট চেকলিস্ট ✅

| # | পরীক্ষা | প্রত্যাশিত |
|---|---|---|
| 1 | নতুন ব্রাউজারে সাইট খোলো | পরীক্ষা LOCKED — বাংলা কাউন্টডাউন (দিন/ঘণ্টা/মিনিট/সেকেন্ড) |
| 2 | অ্যাডমিন → ☁️ সাইন-ইন → মাস্টার সুইচ ON | অন্য ব্রাউজার **রিফ্রেশ ছাড়াই** পরীক্ষা খোলে (Realtime) |
| 3 | সুইচ OFF | সবাই আবার কাউন্টডাউনে ফেরে |
| 4 | ফোনে রেজিস্ট্রেশন করো | "রেজিস্ট্রেশন সফল হয়েছে!" + আইডি; বাটনে "জমা হচ্ছে…" দেখায় |
| 5 | অ্যাডমিন → রেজিস্ট্রেশন তালিকা → রিফ্রেশ/সার্চ | নতুন নাম দেখা যায় |
| 6 | প্রশ্ন যোগ/সম্পাদনা/মুছো → পরীক্ষা খুলে দেখো | নতুন প্রশ্ন, order_no অনুযায়ী সাজানো |

## সমস্যা হলে (কনসোল-কোড ট্রায়াজ)

F12 → Console-এ `[registration]` / `[supabase-db]` লাইন দেখো:

| কনসোলে যা দেখাবে | মানে | করণীয় |
|---|---|---|
| `Could not find the table ... settings` (PGRST205) | **schema.sql চালানো হয়নি** | ধাপ ১ করো |
| `row-level security` / `permission` | পলিসি নেই, বা ☁️ সাইন-ইন করা নেই | ধাপ ১ + ধাপ ২ |
| `relation ... does not exist` | টেবিল নেই | ধাপ ১ করো |
| নেটওয়ার্ক এরর | ভিজিটরের নেট/CDN ব্লক | অন্য নেটওয়ার্কে চেষ্টা |

## নিরাপত্তা — এখনকার মডেল ও পরের ধাপ

- এখন: সবাই পড়তে পারে + রেজিস্ট্রেশন লিখতে পারে + নিজের স্কোর বসাতে
  পারে (RPC দিয়ে, নির্দিষ্ট ফিল্ড ছাড়া কিছু নয়); **settings/questions লেখে
  শুধু signed-in আয়োয়ক** — তাই anon key পকেটে নিয়েও কেউ পরীক্ষা আনলক
  করতে পারবে না।
- পরে (ইভেন্টের আগে): অংশগ্রহণকারীদেরও Supabase Auth দিয়ে সাইন-ইন
  করালে স্কোর-লেখা আরও শক্ত হয়; registrations-এর `select` তখনanon থেকে
  সরিয়ে শুধু RPC-তে আটকে রাখা যাবে।
- ⚠️ service_role key কখনো ক্লায়েন্ট কোডে নয়; চ্যাটে লিক হয়ে থাকলে
  Settings → API → regenerate করে নাও।
